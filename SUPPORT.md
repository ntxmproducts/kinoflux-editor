# Support

Need help with KinoFlux Editor? Here is the quickest way to the right place.

| I want to... | Go here |
|:-------------|:--------|
| Install it, or get past the SmartScreen / Gatekeeper warning | [Install section of the README](README.md#install) and the [install guide](https://ntxm.org/blogs/kinoflux-editor/install-kinoflux-editor-windows-macos/) |
| Know what a tool does and which options it has | [docs/TOOLS.md](docs/TOOLS.md) |
| Check what is stored on my computer | [PRIVACY.md](PRIVACY.md) and [Where your data lives](README.md#where-your-data-lives) |
| See the known limitations | [Known limitations](README.md#known-limitations) |
| Report a bug | [Open a bug report](https://github.com/ntxmproducts/kinoflux-editor/issues/new?template=bug_report.yml) |
| Suggest a feature | [Open a feature request](https://github.com/ntxmproducts/kinoflux-editor/issues/new?template=feature_request.yml) |
| Report a security problem | [SECURITY.md](SECURITY.md) (email, not a public issue) |
| Ask for the source code of the GPL programs in the package | Email [contact@ntxm.org](mailto:contact@ntxm.org), see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) |
| Anything else | [contact@ntxm.org](mailto:contact@ntxm.org) or the [product page](https://ntxm.org/products/kinoflux/videoeditor/) |

When you report a problem, please include your KinoFlux Editor version (About window, <kbd>F1</kbd>), your operating system, the tool you used and the exact message you saw. The log folder is listed in [Where your data lives](README.md#where-your-data-lives). Log files can contain file names, so look at them before you share them. Please do not attach private files.
